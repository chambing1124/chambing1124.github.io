# 奶蛙 NAIWA

个人奶蛙主题互动网站。

网址：https://chambing1124.github.io/

## 功能

**首屏摸奶蛙**

- 单击挤一下、长按抱抱（越抱脸越红）、连点三下鼓腮生气
- 台词随机，并按时间段（早安 / 深夜）、回访（"你回来啦，上次摸了 12 下"）和当前心情变化
- 摸到第 10 / 50 / 100 / 200 / 365 下时，会有一句专属的话和一次光晕
- 奶蛙、光晕、轨道跟随鼠标做视差
- 可选音效（"啵"一声）+ 移动端震动，默认静音

**今日心情**

- 四种心情各有专属插图（松弛蛙 / 勇敢蛙 / 没电蛙 / 开心蛙）
- 切换时整页氛围跟着变：页面底色、首屏光晕、浮签文案、深色模式（没电蛙整体变冷、呼吸变慢）
- 切换有"蹲下换表情再跳起"的过渡
- 首次进入会先问"今天是哪只蛙？"
- "收藏这份心情"会真的存进本地心情日历（最近两周）
- 日历可以点开回看：点某一天，显示那天的心情和一句话；再点收起
- 日历上方显示"连续 N 天"，从今天（或昨天）往前数

**放空计时器**

- 呼吸圆里住着奶蛙，跟着吸气鼓肚子
- 开始后进入沉浸模式：其余内容淡出，只剩奶蛙和计时
- 可选环境声（雨声 / 蛙鸣 / 风声，Web Audio 合成，无音频文件）
- 运行时浏览器标签页标题显示剩余时间和呼吸提示
- 结束后奶蛙伸懒腰，并累计"本周陪你放空了 N 分钟"
- 如果结束时你人在别的标签页，标题会停在"放空结束"，回来时才补一声提示

**心情卡**

- 开卡是信封拆开的动画，"换一句"有翻面过渡
- 卡片上写着当天记录：今天你是哪只蛙、摸了几下、放空了几分钟
- 支持 Web Share API 直接分享图片，桌面端可保存 PNG

**跨模块**

- 一只小奶蛙跟随滚动，在心情区探头、计时区打坐、心情卡区举信封，点它回首屏
- 标题逐字浮现

## 实现说明

纯 HTML、CSS、JavaScript，无构建步骤，无第三方依赖。

- `index.html` — 结构与原样式
- `assets/app.css` — 交互层样式（在原样式之后加载，只做增量覆盖）
- `assets/app.js` — 全部交互逻辑
- `assets/frogs/` — 各心情插图（webp，白底 + multiply 叠色）

数据只存在浏览器本地（`localStorage`，键名前缀 `naiwa-`）：
`mood`、`pets`、`daily`、`week`、`moodlog`、`sound`、`visited`、`lastVisit`。

偏好说明：默认静音；开启声音后才创建 AudioContext。整站尊重 `prefers-reduced-motion`，
开启后关闭视差、逐字动画、呼吸动画与粒子。

预览时可在网址后加 `?nowelcome=1` 跳过首次心情选择。

通过 GitHub Pages 从 main 分支根目录发布。

主题创意页面，非官方。
